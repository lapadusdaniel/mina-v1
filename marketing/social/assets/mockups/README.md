# Mockup-uri MINA

Toate imaginile au fost generate în modul built-in, folosind `public/landing/mina-product-showcase.jpg` drept referință pentru produs și interfață.

## Fișiere și utilizări

1. `01-laptop-travertine-studio.png` — postare de brand, hero sau reclamă premium; fără oameni, 4:5.
2. `02-tablet-phone-flatlay.png` — funcționare cross-device, carousel sau landing page; fără oameni, 4:5.
3. `03-photographer-cafe.png` — fotograf independent și lucru de oriunde; cu om, format vertical.
4. `04-editing-studio-dual-screen.png` — workflow profesionist, website și Facebook; cu om, 3:2.
5. `05-wedding-venue-tablet.png` — relația fotograf–client; cu oameni, 4:5.
6. `06-multi-device-dark-studio.png` — hero premium și prezentarea ecosistemului; fără oameni, 3:2.
7. `07-phone-album-box.png` — livrare digitală + produs fizic; fără oameni, 4:5.

## Prompturi finale

### 01 — Laptop pe travertin

> Use case: product-mockup. Asset type: premium social-media and landing-page mockup for MINA. Input image 1 is the product UI reference and must guide the screen content and visual identity. Create a photorealistic product shot with NO PEOPLE: one slim space-gray laptop open on a sculptural light travertine pedestal in a quiet warm-white photography studio. Show the MINA photographer dashboard/gallery interface from the reference naturally on the laptop display, recognizable as MINA with elegant wedding gallery imagery; keep the interface clean and believable, avoid inventing prominent extra text. Composition: three-quarter front angle from slightly below, generous negative space, vertical 4:5 crop. Lighting: soft directional window light with refined shadows. Palette: ivory, charcoal, champagne, natural stone. Premium European editorial product photography, realistic screen reflections and device proportions. No floating UI, no extra devices, no people, no watermark, no added headline or promotional copy.
